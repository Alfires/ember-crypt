# Ember Crypt repository guidance

- This is independent map source, not the Comunicare client. Do not modify sibling
  projects or include accounts, generated caches or private user data.
- Use Conventional Commits; verify `python3 tests/run.py` and inspect staged paths
  and `git diff --cached --check` before committing. Push only to an explicitly
  configured upstream; never invent a remote or force-push.
- Preserve audited asset provenance and CC0 notices. Never substitute low-poly
  final art or claim the map preview implements combat/progression that is absent.
- Static map scene is generated by `tools/build_map.py`; edit that source and
  regenerate. Preview GDScript is local author tooling, not a safe-world script.
- Do not weaken client validators to publish this project. Validate actual safe
  model/UI/gameplay APIs before adding a separate publication conversion step.
